# ADR 0001: Write wt as a single Bash script

Status: accepted, 2026-10-24.

## Context

`wt` wraps a handful of `git` commands. It must install in one command on macOS and Linux and pull in no heavy dependency.

## Options

- **Go binary.** Fast and typed. Needs release builds per OS and architecture, or a Go toolchain on the user's machine.
- **Node CLI.** Familiar, but needs Node and npm and adds a startup cost to every call.
- **Bash script.** Runs wherever `git` runs. Install is a `curl` of one file.

## Decision

Bash. Every operation is a call to `git`, so a compiled language would add packaging work without removing complexity.

Rules that follow from this:

- Stay compatible with Bash 3.2, the version macOS ships. No associative arrays, no `mapfile`, no `${var,,}`.
- Let Git do the parsing. Config files use Git's config format (`git config -f`), exclude globs are Git pathspecs, and worktrees come from `git worktree list --porcelain`.
- Keep the script `shellcheck`-clean.

## Consequences

- No build step and no release artifacts.
- Tests are plain Bash against real temporary repositories. No test framework to install.
- If `wt` grows past a few hundred lines or needs Windows support, revisit this choice.
